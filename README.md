# 탄생석 보석함

휴대폰을 손에 올려놓고 기울이면, 열두 달 탄생석의 면마다 빛이 번쩍이고 색이 깊어지는 모습을 감상하는 웹페이지입니다.

## 기능
- 컷마다 면 구조를 만들어 실시간 광선 추적으로 굴절·전반사·색 분산·색 흡수를 계산
- 바닥에 떨어지는 그림자와 그 안의 빛 무늬(투명한 보석은 보석 색으로 물듦)
- 진주의 광택, 오팔의 유색 효과, 터키석의 매트릭스 무늬
- 에메랄드의 자르댕(이끼 같은 내포물), 사파이어의 실크(가는 바늘 내포물)
- 알렉산드라이트: 기울이는 방향에 따라 햇빛(초록)과 등불(붉은빛) 아래의 색으로 바뀜
- 스타 사파이어: 기울이면 여섯 줄기 별빛이 표면 위를 움직임
- 휴대폰을 기울이면 보석이 손 위에서 구르듯 따라 돌고(무게감 있는 출렁임), 흔들면 관성이 남음. 센서가 없으면 화면을 끌어서 돌림
- 전체 화면: 안드로이드·데스크톱은 열 때 자동, 아이폰은 '홈 화면에 추가'로 열면 주소창 없이 표시 (manifest.webmanifest, 아이콘 포함)
- 조명 4가지(보석상·햇살·촛불·스포트라이트)와 바닥 4가지(검은 벨벳·흰 실크·대리석·원목)를 골라 볼 수 있음. 고른 것은 다음에 열 때도 기억함
- 보석 위를 쓸면 보석을 뒤집고 돌려 볼 수 있음(손을 떼면 관성으로 조금 더 돎). 바탕을 옆으로 쓸면 다음 보석
- 달 칩·화살표·옆으로 넘기기로 전환, 두 손가락·두 번 탭·+/− 버튼으로 확대
- 주소 끝에 `#m1`~`#m12`를 붙이면 그 달의 보석으로 바로 열림 (기본은 이번 달). `#m6a`는 알렉산드라이트, `#m9a`는 스타 사파이어
- 카카오톡·페이스북 등 인앱 브라우저에서 열면 기본 브라우저로 다시 열기
